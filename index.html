Conociendo git y Github

Giancarlo Chacón Chavarría

¿Que es Git?

Git es un programa que instalas en tu computadora para llevar el historial de cambios de un proyecto. Te permite revisar qué se modificó, cuándo se hizo y volver a una versión anterior si algo falla o se borra por accidente.

Ventajas de utilizar Git

  • Permite regresar a versiones anteriores del proyecto si ocurre algún error.
  • Facilita el trabajo en equipo sin sobrescribir los cambios de otras personas.
  • Funciona directamente en la computadora sin depender de una conexión a internet.

¿Qué es GitHub y para qué se utiliza?

GitHub es una plataforma en la nube donde puedes subir tus proyectos manejados con Git. Se utiliza para guardar respaldos en internet, compartir el código con otras personas y trabajar en equipo sobre un mismo proyecto sin perder los cambios.

Comandos básicos de Git

  • git init inicia un repositorio nuevo de Git dentro de la carpeta del proyecto.
  • git add agrega los archivos modificados al área de preparación antes de guardarlos.
  • git commit guarda los cambios preparados en el historial del proyecto con un mensaje descriptivo.
  • git push envía los cambios guardados localmente hacia el repositorio remoto en GitHub.
